# 📋 Plantilla para Nueva Iteración

> **Cómo usar:** Copia esta plantilla cuando vayas a lanzar un nuevo sprint o ciclo de trabajo con la IA. Puedes pegarla en el chat o guardarla como `iteracion_XX.md`.

---

```markdown
### 🚀 Iteración #[NÚMERO]: [TÍTULO CORTO DE LA ITERACIÓN]

#### 1. Objetivo Principal
- [Describe en 1 o 2 frases qué se espera lograr en este ciclo, ej. "Construir la barra de navegación y el Hero section interactivo"].

#### 2. Entradas y Referencias a Considerar
- Aspectos Funcionales: Consultar `prompts/funcionales/01_vision_y_audiencia.md` y `prompts/funcionales/02_mapa_del_sitio_y_flujos.md`.
- Aspectos Técnicos: Consultar `prompts/tecnicos/01_stack_tecnologico.md` y `prompts/tecnicos/03_diseno_y_ui_ux.md`.

#### 3. Tareas Específicas
1. [ ] Crear / modificar archivo X con tales características...
2. [ ] Implementar interacción Y (ej. responsive toggle de menú)...
3. [ ] Ajustar estilos visuales conforme a los tokens de color definidos...

#### 4. Criterios de Aceptación (Definición de Terminado)
- [ ] La UI se visualiza correctamente en escritorio y móvil sin desbordamientos.
- [ ] No hay errores de consola.
- [ ] La experiencia interactiva y micro-animaciones responden con fluidez.
```
